# Features

> Fitur konkret per versi (WHAT, siap diimplementasi). Requirement & rationale di balik tiap fitur → `PRD.md`.

---

## MVP (v0.1.0)

- [ ] Login via Google OAuth
- [ ] Homepage (list gawean, cek berkala gawean baru)
- [ ] Profile Page (lihat & edit nama/foto profil, isi nomor telepon wajib, logout)
- [ ] Post Gawean (judul, deskripsi, checklist tugas, biaya, lokasi, waktu, lama bekerja)
- [ ] Detail Gawean (lihat detail & status, Tawarkan Diri, nego harga one-shot)
- [ ] Postingan Saya (lihat & terima Gawers yang menawarkan diri)
- [ ] Sedang Gawe — UI Gawers (checklist, timer deadline, nomor telepon Bos Gawe, tombol selesai/cancel)
- [ ] Sedang Memantau — UI Bos Gawe (pantau progress checklist, nomor telepon Gawers, tombol terima/cancel)
- [ ] Notifikasi (dua arah: Bos Gawe & Gawers)
- [ ] Pertukaran nomor telepon otomatis setelah Application diterima
